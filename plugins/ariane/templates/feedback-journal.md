# Journal de retours d'expérience sur Ariane

Ce journal aide Ariane à s'améliorer. Il n'est tenu qu'avec l'accord de l'utilisateur, reste sur son ordinateur et n'est pas versionné dans Git. La commande `/ariane:feedback` en tire un compte rendu à partager.

Format d'une entrée :

```
## AAAA-MM-JJ HH:MM · <phase ou story> · <agent>

- Ce qui s'est passé : …
- Ce qui a bien marché : …
- Frictions ou blocages : …
- Corrections demandées par l'utilisateur : …
- Erreurs ou comportements inattendus des agents : …
- Durée approximative : …
- Idée d'amélioration pour Ariane : …
```

Ne jamais y écrire de secret, ni de donnée personnelle des futurs utilisateurs de l'application.
