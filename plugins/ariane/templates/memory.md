# Mémoire du projet

Ce fichier est chargé dans **chaque** session et dans **chaque** spécialiste lancé : chaque ligne se paie à chaque fois. Il ne contient donc que **l'essentiel à appliquer tout le temps**. Plafond : **60 entrées**, une ligne chacune.

Ce qui va ici : qui est l'utilisateur, ce qu'il préfère, les grandes décisions, les conventions du projet, ce qu'il ne faut jamais refaire.

Ce qui ne va **pas** ici :
- une recette technique, un contournement, le détail d'un outil ou d'un service → le **carnet technique**, `.ariane/notes/<sujet>.md`, lu seulement quand on travaille sur ce sujet ;
- ce qui s'est passé et quand → le journal de bord, `.ariane/log.md` ;
- ce qui ne sert plus qu'à l'histoire du projet → `.ariane/history/`, rangé par lot et par version.

Règles d'écriture :
- une entrée = une ligne courte, datée, avec l'agent qui l'a écrite : `- 2026-10-09 · Ada · …` ;
- actionnable (« Faire X », « Ne pas faire Y, parce que Z ») ;
- jamais de secret (clé, mot de passe) ;
- une consigne de l'utilisateur prime sur tout le reste ;
- quand une entrée devient fausse, la corriger ou la supprimer plutôt qu'en ajouter une contradictoire ;
- avant d'ajouter une entrée, se demander : « faut-il vraiment que tout le monde la relise à chaque fois ? ». Sinon, c'est une note du carnet.
